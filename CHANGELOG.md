# Changelog

Every tag of sentient-ui-types is a SENTIENT release and is generated from that
release's `ui-ngx`, so its changes are the release's changes:

- Release notes: https://github.com/QuakeString/sentient-release/releases (tag `<version>`)
- SENTIENT's CHANGELOG.md, where changes to the public UI API that extensions
  compile against are marked **Extension API**.

This tag: 4.3.0.59 (https://github.com/QuakeString/sentient-release/releases/tag/4.3.0.59).
